Panduan Penggunaan

admin_panel_settings KHUSUS PANITIA

  • 1 Masuk Room: Pilih game, buat KODE ROOM unik (Cth: MEJA1).
  • 2 Login Admin: Klik "Admin Login". Password standar: admin123.
  • 3 Setup Pemain: Isi data pemain.
    ⚠️ Simpan = Reset Skor.
  • 4 Input Skor: Masukkan hasil Rank. Tersimpan otomatis via Firebase.
  • 5 Share Link: Klik icon Share di atas judul untuk mengirim link ke peserta.

groups PESERTA / PENONTON

  • 1 Akses Link: Buka link yang dibagikan panitia.
  • 2 Kode Room: Jika diminta, masukkan KODE ROOM dari panitia.
  • 3 Live Update: Skor di HP Anda akan berubah otomatis secara real-time. Tidak perlu refresh!
  • 4 Cek Klasemen: Buka tab klasemen untuk melihat total poin.

Tanya Jawab

Apakah web ini boros kuota?
Sama sekali tidak. Web ini didesain text-based menggunakan Firebase Realtime Database. Ukuran data yang dikirim per detik hanya hitungan byte.
Bagaimana cara mengubah nama pemain yang salah ketik?
Login sebagai Admin → Klik tombol "Edit Nama Pemain" di menu Admin → Ganti Nama → Klik Simpan.
Mengapa saya tidak bisa menekan tombol input skor?
Hanya Panitia (Admin) yang diizinkan mengubah skor. Anda berada dalam mode penonton (View Only). Jika Anda panitia, pastikan sudah klik "Admin Login".
